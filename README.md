# חידון המשפחה LIVE

אפליקציית חידון משפחתית בזמן אמת בסגנון Kahoot. החיבור בין המכשירים מתבצע ישירות ומוצפן באמצעות WebRTC/PeerJS, ולכן ניתן לארח את האתר ב-GitHub Pages ללא שרת Node.js.

## האתר

`https://naftalibarber.github.io/A-Kahoot-style-game/`

מחשב המנחה חייב להשאיר את עמוד המשחק פתוח לאורך המשחק, וכל המשתתפים צריכים חיבור לאינטרנט.

## הרצה מקומית

```bash
python -m http.server 8000 --directory public
```

פתחו `http://localhost:8000`. אין לפתוח את `index.html` ישירות כקובץ, מפני שטעינת JSON דורשת שרת HTTP.

## עריכת שאלות

ערכו את `public/questions.json`. המשחק בוחר באקראי 2–6 שאלות מהמאגר. `correctAnswer` הוא אינדקס שמתחיל ב-0 בבחירה/כן-לא, או מחרוזת (וגם מערך של איותים חלופיים) בשאלת טקסט. בדיקת טקסט מתעלמת מרווחים מיותרים ומהבדלי אותיות קטנות/גדולות.

אפשר להוסיף תמונה או GIF באמצעות כתובת מלאה בשדה `mediaUrl`.

## חשבון מנהל

במסך הבית לחצו על `ניהול חידונים` והתחברו באמצעות משתמש Email/Password שנוצר ב-Firebase Authentication. מנהל מחובר יכול ליצור, לערוך ולמחוק חידונים הנשמרים ב-Cloud Firestore. יש לפרסם ב-Firestore את הכללים שבקובץ `firestore.rules`; הם מאפשרים לכולם לקרוא חידונים ורק למשתמש מחובר לשנות אותם.

## פרסום אוטומטי

ה-Workflow שב-`.github/workflows/pages.yml` מפרסם את התיקייה `public` ל-GitHub Pages בכל push לענף `main`.

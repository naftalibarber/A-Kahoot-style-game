# חידון המשפחה LIVE

אפליקציית חידון משפחתית בזמן אמת בסגנון Kahoot: מסך מנחה למקרן ומסך שחקן מותאם לטלפון. כוללת שאלות בחירה מרובה, נכון/לא נכון והקלדת טקסט, ניקוד לפי מהירות, התפלגות תשובות ולוח מובילים.

## הרצה

נדרשים Node.js 18 ומעלה.

```bash
npm install
npm start
```

פתחו במחשב המנחה `http://localhost:3000`. כדי ששחקנים יתחברו מאותה רשת Wi-Fi, מצאו את כתובת ה-IP המקומית של מחשב המנחה ופתחו בטלפון, למשל `http://192.168.1.20:3000`.

## עריכת שאלות

ערכו את `public/questions.json`. המשחק בוחר באקראי 2–6 שאלות מהמאגר. `correctAnswer` הוא אינדקס שמתחיל ב-0 בבחירה/כן-לא, או מחרוזת (וגם מערך של איותים חלופיים) בשאלת טקסט. בדיקת טקסט מתעלמת מרווחים מיותרים ומהבדלי אותיות קטנות/גדולות.

אפשר להוסיף תמונה או GIF באמצעות כתובת מלאה בשדה `mediaUrl`.

## פריסה באינטרנט

זהו שרת Node.js עם WebSockets, לכן יש לפרוס אותו בשירות שתומך בחיבור מתמשך כגון Render, Railway או Fly.io. GitHub Pages לבדו אינו מתאים לסנכרון בזמן אמת.
